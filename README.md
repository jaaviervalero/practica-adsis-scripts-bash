# Scripts de administración de sistemas en Bash

Prácticas de **Administración de Sistemas** (Ingeniería Informática, Universidad de Zaragoza, curso 2025-26).

- `pr2/`: ejercicios de introducción a Bash.
- `pr3/`: alta y baja masiva de usuarios a partir de un fichero CSV, con validación de la entrada, contraseña, caducidad y copia de seguridad del home al borrar. Incluye la memoria (`practica_3.md`).
- `pr4/`: el mismo script ejecutado en varias máquinas remotas por SSH con autenticación por clave pública. Incluye la memoria (`practica4.md`).
- `pr6/`: discos, particiones (GPT, `parted`, `fstab` por UUID), un script que consulta por SSH la información de discos de otra máquina, y gestión de LVM (grupos y volúmenes lógicos). Incluye la memoria (`practica6.md`).

Los scripts se validaron con los tests de [agusnt/UZ_Practicas_AS](https://github.com/agusnt/UZ_Practicas_AS).
